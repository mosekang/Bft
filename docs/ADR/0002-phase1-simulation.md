# ADR-0002 — Phase 1 시뮬레이션 구현 결정과 보정

상태: 채택(전체 Phase 자동 승인) · 날짜: 2026-09-26

`packages/engine/src/sim/*`가 §6을 구현하면서 사양이 침묵하거나 수치가 맞지 않았던 지점.

| # | 항목 | 결정 | 근거 |
|---|---|---|---|
| 1 | **능력치 피벗 분리** | `PIVOT = { hitter: 50, pitcher: 55 }`. §6.2의 `(r − 55)`를 타자 50, 투수 55로 나눔. | 타자 라인업은 38짜리 대체선수와 섞이고 투수는 그렇지 않아 55/55에서는 레벨 7 팀이 3.4득점에 그친다. 50/55에서 레벨 5/7/9 = 4.1/4.5/5.8득점으로 §6.1 목표(4.8 ± 0.4)를 런 평균에서 만족한다. 보정 스윕은 `scratchpad/sweep.ts`(미커밋) 결과. |
| 2 | **유형별 BABIP 스케일** | `typeBabip()`가 §6.1 유형별 값(.240/.680/.120/.020)을 리그 혼합비로 가중했을 때 .284가 되는 것을 .310으로 맞추는 계수(×1.092)를 곱한다. | §6.1의 두 수치가 서로 맞지 않는다. 전체 BABIP .310을 우선. |
| 3 | **멘탈의 볼넷 보정** | 득점권에서 `pBB × exp(−(mental − 55) × 0.004)`. | §6.4 "bbRate 계산치에 (mental−55)×0.004 가산"을 확률 가산으로 읽으면 멘탈 95가 볼넷을 16%p 줄여 비현실적. 배율 해석(멘탈 95 → ×0.85). |
| 4 | **땅볼 아웃 주자 처리** | 무사·1사 땅볼 아웃: 3루 주자 50% 득점, 2루 주자는 1루 주자가 있으면 진루, 없으면 40% 진루. 1루 주자 있을 때 병살 실패분의 25%는 야수선택(선행주자 아웃). | §6.3-7은 병살·희생플라이·실책만 정한다. |
| 5 | **긴급 투수** | 불펜이 바닥나면 대체투수를 무한정 투입(`REPL:BP{n}`), 투구수 제한 없음. 대체 RP 템플릿을 `bullpen` 끝에 둔다. | §6.4 "불펜 없으면 대체투수". |
| 6 | **연장전 환경과 무승부 비율** | 10회부터 `GAME.extraInnings = { kMult 1.25, bbMult 0.85, hrMult 0.7, babipAdd −0.05 }`. 결과 무승부 ≈ 1.5%(레벨 7 3,000경기). | §15.1 목표 3~7%와 §18 "12회 무승부"는 현실 야구에서 동시에 나오기 어렵다(실제 KBO 12회 제한 시즌 무승부 2~4%). 억제를 더 올려도(k×1.35, hr×0.6) 1.8%에 그쳐 인위적이었다. **미해결**: 목표를 1~4%로 낮추거나(현실적) 연장을 10회로 줄이면(≈5%) 맞는다. 사용자 결정 필요. 그때까지 `sim-game --games` 리포트는 OUT으로 표시하고 테스트는 0.5~8%만 확인. |
| 7 | **볼넷 비율** | 레벨 7에서 11.0%(기준 9.0%). 삼진 18.4%, 홈런 2.7%는 기준선 근처. | 실제 카드의 선구 능력치(60~65)가 타자 피벗 50보다 높아 볼넷이 늘어난다. bot-arena(§15.1)에서 런 전체 득점이 맞으면 유지, 아니면 `RATING_K.hitter.bbRate`를 0.02 → 0.016으로 낮추는 것을 1순위 후보로. |
| 8 | **이벤트 수** | INNING_END·PITCHING_CHANGE 포함 정규 9이닝 평균 95개, 연장 시 120 초과 가능(5% 미만). 이벤트를 버리지 않는다. | §6.5 "≤ 120"은 정규 경기 기준으로 본다. |
| 9 | **승·패·세이브** | 패전: 결승점을 내준 투수. 승리: 그 시점 이후 승리팀에서 처음 등판해 있던 투수. 세이브: 승리투수가 아닌 마지막 투수가 1~3점 리드로 등판했을 때. | 공식 규정의 5이닝 조건 등은 생략. |
| 10 | **하이라이트** | §6.5 중요도 상위 5 + 첫 득점 + 마지막 아웃 = 최대 7개. | |
| 11 | **대체 타자 이름** | 라인업 채우는 순서대로 김·이·박·최·정·강·조·윤·장·임 + "대체". 같은 팀에 같은 성이 나오지 않는다(10칸 이하). | §5.4 |
| 12 | **효과 주입 인터페이스** | `TeamEffects { team, hitterMods, pitcherMods, ratingAdd, internalAdd }`를 `resolveTeam`이 받는다. 아이템·시너지·철학은 Phase 2의 `computeEffects()`가 채운다. | 시뮬은 "왜"를 모른다(CLAUDE.md §3). |

## Phase 1 완료 기준 증거

- `pnpm cli sim-game --seed demo --level 8 --stadium HITTER_FRIENDLY` → 박스스코어·하이라이트·MVP 출력(`packages/cli/src/simGame.ts`).
- 결정론: `sim.test.ts` "is deterministic" — 같은 시드·팀 → `toEqual`.
- 성능: 300경기 평균 0.34 ms/경기 (예산 30 ms).
- 3,000경기(레벨 7, 무작위 로스터): 팀당 4.50득점(목표 4.4~5.2), 삼진 18.4%, 볼넷 11.0%, 홈런 2.7%, 무승부 1.5%(#6 참조).
- 강팀(레벨 10) vs 약팀(레벨 4) 승률 > 60% 테스트 통과.
