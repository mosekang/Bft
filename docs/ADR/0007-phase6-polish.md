# ADR-0007 — Phase 6 재미 레이어·온보딩·성능·배포 준비

상태: 채택(전체 Phase 자동 승인) · 날짜: 2026-09-26

| # | 항목 | 결정 | 근거 |
|---|---|---|---|
| 1 | **타순 액션** | 프로토콜에 `SET_ORDER{order: Pos[9] \| "AUTO"}` 추가. 웹은 "타순 편집" 시트(위/아래)와 "타순 자동"(엔진 `autoOrder`: OVR·별 순). | §12.3에 타순 메시지가 없었다. MOVE의 "칸 좌표"로는 순서를 표현할 수 없다. |
| 2 | **중계 톤 2종** | 캐스터 문장 뒤에 50% 확률로 해설 코멘트를 덧붙인다(이벤트 좌표 시드로 결정적). | §14.6 "톤 2종". |
| 3 | **연출** | 홈런: 배경 플래시 500ms + (옵션) 진동 80ms. 별 합성: 카드에 `sparkle` 400ms(별이 오를 때 리마운트). `prefers-reduced-motion`이면 애니메이션·전환 제거. | §14.3, §14.4 |
| 4 | **온보딩** | 1-1 준비 단계에서 3단계 코치마크(상점→보드→경기). "다시 보지 않기"는 설정 `coachmarks`. | §14.5 |
| 5 | **성능 예산** | 메인 번들 181 KB gzip(예산 400), 워커 청크 별도. 라운드 전환은 Worker 왕복 + 렌더로 수십 ms. CI가 gzip 크기를 검사한다. | §14.2 |
| 6 | **배포** | Cloudflare 자격 증명이 없어 배포 URL은 만들지 못했다. `docs/DEPLOY.md`와 `.github/workflows/deploy.yml`(workflow_dispatch)로 절차를 고정. | §17 Phase 6 "배포 URL" 미충족 — 사용자 환경에서 실행 필요. |
| 7 | **밸런스 재검증** | Phase 6에서 엔진 규칙 변화가 없어(고스트 오버레이·타순 액션만) ADR-0003의 1000판 결과가 유효. 미해결 2건(무승부 비율, 5코 ★★) 유지. | |
| 8 | **CI** | `.github/workflows/ci.yml`: typecheck → test → pack:validate → bot-arena 100판 스모크(범위 밖이면 경고) → 웹 빌드 → 번들 예산 → Playwright e2e. | §16 CI |

## §15.3 체크리스트 상태
- 첫 진입 → 첫 경기 90초: 로비 → 새 게임 → 구장 선택 → 1-1 준비 → 경기 시작. e2e 기준 수 초. ✔
- 한 판 25분: 봇 런은 라운드당 수 ms; 사람 플레이 시간은 준비 시간에 좌우. 연출 즉시 모드 제공. (실측 불가)
- "왜 졌는지": 경기 화면에 상대 이름·점수·하이라이트, 상대 미니 상태 탭 → 보드·시너지·구장 미리보기. ✔ (플래툰 표시는 후속)
- 친구방 4명 3판 무중단: Node 서버 + 2 브라우저 컨텍스트 e2e로 대체. 실기기 미측정.
