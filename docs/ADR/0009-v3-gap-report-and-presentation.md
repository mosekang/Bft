## 2. 사양과 다르게 한 결정

1. **에셋은 전부 코드로 생성한다.** Mixamo는 계정 다운로드가 필요하고, 이 환경에는 Blender가 없으며, 출처 추적이 가장 확실한 방법이 "저장소 코드가 곧 원본"이다. 캐릭터는 부위(몸통·머리·팔다리·모자·헬멧·배트·글러브·등번호 데칼…)마다 InstancedMesh 하나라서 30체 기준 드로우콜이 약 40이다(예산 60). 클립 이름·루프·폴백 표는 §15.4 그대로이고 `packages/assets` 검증기와 `scene.test.ts`가 누락을 막는다. GLB 파이프라인은 필요해지면 같은 클립 이름으로 교체할 수 있다.
2. **렌더 좌표는 x를 뒤집는다.** 사양 좌표(3루 = −x)를 홈 뒤 카메라로 그대로 보면 좌익수가 화면 오른쪽에 온다. 렌더 공간은 3루 = +x로 두고 `specToWorld`로 변환한다. 엔진·cinematic 데이터는 사양 좌표 그대로.
3. **사운드는 Web Audio 합성.** 에셋 0바이트, 라이선스 문제 없음, iOS 언락·채널 3개·음소거 유지. 31종(사양 목록 그대로 세면 31) + 16초 로비 루프.
4. **low 등급 = 2D.** 사전 렌더 스프라이트에는 Blender가 필요하다. WebGL2 불가·첫 2초 30fps 미만·자동화 브라우저(webdriver)는 2D 보드와 텍스트 중계로 떨어진다. `?q=high|mid|low`로 강제 가능.
5. **준비 단계 카메라와 배치.** 사양 카메라 (0,22,−18)→(0,0,20)은 세로 화면에 외야가 들어오지 않는다. 타깃 (0,0,30), 고도 54°에서 12칸이 다 들어오는 거리로 자동 맞춘다(±12° 패럴랙스 유지). 준비 단계 인물은 체스 말 크기(5.4배)이고 외야 칸을 안쪽으로 당겼다(LF/RF (±31,58), CF (0,66)). 경기 연출은 실제 좌표와 1.25배 인물.
6. **CAM_PITCH·CAM_BOARD 보정.** 포수 뒤 (0,1.6,−4)는 심판과 포수에 가려 (−1.1,2.8,−6.4)로 올렸다. 전광판은 구장별 실제 위치(중견수 펜스 + 44m)를 찍는다.
7. **drei 제거.** HTML 라벨은 카메라가 바뀔 때만 투영하는 DOM 레이어 하나로 대체했다(매 프레임 12개 DOM 갱신 제거, e2e 핸들 `button[data-slot]`).
8. **블룸 없음.** 후처리 의존성 대신 가산 글로우 스프라이트·화면 플래시로 홈런을 강조한다.

## 3. KBO 차용 방식

- 가상 구단 10개를 KBO식 "도시 + 애칭"과 두 가지 색 유니폼(핀스트라이프·사선 띠·소매 배색)으로 바꿨다: 서울 코메츠, 서울 팔콘스, 인천 하버스, 수원 캐슬스, 대전 로켓츠, 대구 블레이즈, 광주 피닉스, 부산 오션스, 창원 매머드, 고척 메테오스. 실제 구단명·엠블럼·응원가는 쓰지 않는다. 카드 데이터는 바뀌지 않았다(팀 표시 정보만 추가).
- 구장 분위기: 응원단상과 치어리더, 막대풍선 든 관중, KBO식 전광판(1~12회, R·H·E, B·S·O), 내 공격 때 응원 북 루프.
- 초상화: 카드 사진 대신 KBO 카드 느낌의 SVG(팀색 헬멧·모자, 유니폼 패턴, 워드마크, 등번호, 아이블랙). 외형은 3D 캐릭터와 같은 결정론 모델에서 나온다.
- 실제 선수로 하고 싶으면: 설정 → "CSV로 내 리그 만들기"에 타자·투수 CSV를 넣으면 기기 안에서 바로 팩으로 변환된다(서버 업로드·저장소 커밋 없음, §2).

## 4. 증거

- 테스트: engine 72, cinematic 76, web(단위) 29+, server 12, assets 2 등 전체 통과 (`pnpm test`).
- e2e(Pixel 5): `v3.spec.ts` 3D 보드 + 3D 중계 + 스킵 통과(16.5초), CSV → 개인 팩 통과. 솔로·친구방은 ADR 0004·0005 흐름(2D 등급) 그대로.
- 번들(gzip): 메인 약 194KB + 3D 청크 약 237KB + 중계 청크 약 17KB (예산 600KB). 로비는 3D를 받지 않는다.
- 스크린샷: 준비 단계 3D 보드, 투구 샷, 홈런 공 추적, 필드 샷(작업 중 확인).
