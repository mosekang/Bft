# 덕아웃 택틱스 (가제) — 게임 설계 문서

> **한 줄 컨셉**: TFT(전략적 팀 전투)의 룰로 하는 야구. 상점에서 선수 카드를 사서 타순과 로테이션을 짜면, 경기는 자동으로 돌아간다. 한 판 20~25분, 서버 없음, 과금 없음.
> **1차 목표**: 모바일 웹(PWA). 스토어 앱은 후속(Capacitor).
> 이 문서는 착수 프롬프트의 정리본이며, 규칙·수치·결정의 기준이다. 코드와 어긋나면 **문서를 먼저 고치고** 코드를 따라오게 한다. 수치의 실제 값은 `packages/engine/src/data/*`가 원본이고, 이 문서는 의도와 초기값을 적는다.

## 1. 차별점 (핵심 훅 4개)

1. **대체선수 시스템** — 보드는 타순 9칸 + 투수 3칸 = 12칸이 항상 차 있다. 내 **레벨만큼만 진짜 선수**를 넣을 수 있고 나머지는 능력치 평균 이하의 **대체선수**("김대체", "이대체"…)가 자동으로 선다. WAR의 기준점인 "대체 수준 선수"가 모티브. 최대 레벨(10)에서도 2칸은 대체선수 → "완벽한 팀"은 없다.
2. **투수 피로 = 자원 관리** — 이번 라운드 던진 선발은 다음 2라운드 동안 지친다. 로테이션 운용이 경제만큼 중요하다.
3. **좌우 플래툰 가위바위보** — 좌타 라인업은 우완에 강하고 좌완에 약하다. 상대 7팀의 로테이션을 보고 타순을 바꾸는 심리전.
4. **구장이 곧 보드** — 시작 시 홈구장을 고른다. 시너지와 궁합이 맞아야 한다.

**톤**: 진지한 야구 지식 위에 가벼운 유머. 캐스터/해설 말투의 텍스트 중계. 선수마다 한 줄 별명.

## 3. 한 판의 구조

- **8팀 토너먼트**: 나 + AI 7팀. 모두 같은 카드 풀(내가 산 카드는 남이 못 산다).
- **팬심 100**: 지면 `clamp(실점차 + 스테이지 보정, 2, 25) × 라운드 배율`만큼 깎인다. 0이면 탈락. (`data/damage.ts`)
- **라운드** = 준비(상점·배치, 시간 제한 없음, 수동 진행) → 경기(자동 시뮬, 하이라이트 15~20초, 스킵 가능).
- **스테이지** (`data/schedule.ts`, 총 26라운드):

| 스테이지 | 라운드 | 내용 |
|---|---|---|
| S1 스프링캠프 | 1-1 ~ 1-3 | 훈련팀 PvE, 아이템 드롭. 끝나면 **감독 철학** 1개 선택(2-1 직전) |
| S2 ~ S6 정규시즌 | x-1 ~ x-4 | x-1: **FA 시장**(카러셀, 팬심 낮은 순) 후 PvP · x-2, x-3: PvP · x-4: 이벤트 |
| S7 포스트시즌 | 7-1 ~ 7-3 | 남은 팀끼리, 데미지 2배. 7-1, 7-2 플레이오프, 7-3 결승 3전 2선승 |

- 이벤트: 2-4 올스타전(아이템) · 3-4 우천취소(골드만, 투수 피로 회복) · 4-4 트레이드 마감(벤치 1명 ↔ 풀의 같은 코스트 카드) · 5-4 레전드 매치(PvE 보스 "88년 그 팀") · 6-4 올스타전.
- 감독 철학 선택: 2-1 직전, 3-2 직전, 5-2 직전 (총 3회).

## 4. 경제·상점 (`data/economy.ts`, TFT 초기값, 튜닝 대상)

- 라운드 수입 5 + 이자(10골드당 1, 최대 5) + 연승/연패 보너스(2·3·5연 이상: +1/+2/+3).
- 상점 5장, 리롤 2골드, 경험치 4골드(=4XP), 라운드마다 2XP 자동.
- **레벨 = 진짜 선수를 둘 수 있는 칸 수.** 시작 3, 최대 10. 보드 12칸.
- 레벨업 XP: 3→4: 6, 4→5: 10, 5→6: 20, 6→7: 36, 7→8: 48, 8→9: 76, 9→10: 84.
- 코스트 1~5. 풀 매수(카드당): 29 / 22 / 18 / 12 / 10. 종류 수: 14 / 13 / 13 / 12 / 8.
- 레벨별 등장 확률(%): TFT 표(`SHOP_ODDS`). 예: Lv5 = 45/33/20/2/0, Lv8 = 17/24/32/24/3.
- **별 등급**: 같은 카드 3장 → ★★(주전), ★★ 3장 → ★★★(프랜차이즈 스타). 능력치 상승 + 별명 진화.
- 벤치 6칸. 판매는 코스트 환불(★★ 이상은 합산, 1코스트 외에는 −1).
- 아이템은 카드당 최대 2개.

## 5. 선수 카드와 시뮬 엔진

### 5.1 능력치 (`types/player.ts`)
- **타자 표시치 5**: 컨택 / 파워 / 선구 / 스피드 / 수비. **내부치**: 좌·우 상대 분리 컨택, 삼진율, 볼넷율, 홈런율, 땅볼·뜬공 성향, 도루 성공률, 포지션별 수비, 어깨.
- **투수 표시치 5**: 구위 / 제구 / 무브먼트 / 스태미나 / 멘탈. **내부치**: 삼진율, 볼넷율, 피홈런율, 땅볼 유도율, 좌·우 플래툰 계수, 구위 하락 시작 투구수와 기울기, 팔각도(플래툰 폭).
- 카드마다 타석 방향(좌/우/양), 투구 팔(좌/우), 포지션 적성(주/부), 나이, 특성(trait) 목록.
- 카드 종류: `BATTER` / `STARTER` / `RELIEVER`.

### 5.2 타석 결과 (`types/game.ts`, 기준선은 `data/baseline.ts`)
1. **Log5(오즈비)**: 타자 성향, 투수 성향, 리그 평균을 결합해 볼넷 / 사구 / 삼진 / 홈런 / 인플레이 확률을 만든다.
   Log5: `p = (pB × pP / pL) / ((pB × pP / pL) + ((1−pB)(1−pP)/(1−pL)))` — 두 대결 상대의 확률과 리그 평균으로 "이 매치업에서 실제 일어날 확률"을 구한다.
2. **Modifier 적용**: 플래툰, 구장, 투수 피로, 시너지, 아이템, 감독 철학, 주자 상황. 모두 `Modifier` 데이터(`types/modifiers.ts`).
3. **타구 판정**: 인플레이면 타구 유형(땅볼/라인/뜬공/팝업)·방향 → 담당 수비수 능력으로 안타/아웃/실책 (골든글러브 시너지 개입). 안타는 1/2/3루타 배분.
4. **주루**: 스피드 vs 외야 어깨. 도루는 스피드스터/스몰볼이 자동 시도.
- 기준선: KBO 수준(팀당 4.5~5.5득점). 9이닝 풀 시뮬, DH 사용. 1경기 50ms 이내.

### 5.3 투수 피로 (`data/fatigue.ts`)
- 선발: 등판 후 **2라운드 피로**. 피로 중 등판 시 능력치 ×0.7, 부상 확률 15%(부상 3라운드). 선발 3명이면 딱 맞아떨어진다.
- 불펜(코스트 낮음, 스태미나 낮음): 매 라운드 등판 가능, 경기당 최대 2이닝. 마무리 시너지와 결합.
- 경기 중 교체는 엔진의 AI 감독이 자동(투구수·리드·피로 기준). 사용자는 **로테이션 순서**와 **불펜 데이** 여부만 정한다(`Board.bullpenDay`).

### 5.4 이름·별명 생성기 (Phase 1/4)
- 한국식 가상 이름(중복 최소화), 외국인은 국적별 풀. 실명·실제 구단 사용 금지.
- 별명은 능력치 조합에서 자동 생성("발만 빠른 남자", "볼넷 공장장", "좌완 킬러"). 별 등급마다 별명 3단계(`nicknames: [★, ★★, ★★★]`).

## 7. 아이템과 감독 철학

- **아이템** (`types/item.ts`): PvE·이벤트 라운드에서 드롭. 기본 6종 — 배트(파워), 스파이크(스피드), 글러브(수비), 로진백(제구), 아이싱(피로 회복), 전력분석(상대 로테이션 공개). 둘을 합치면 특수 아이템: 배트+스파이크 = "호타준족", 로진+아이싱 = "철완", 전력분석+글러브 = "수비 시프트" 등 (조합표는 Phase 2에서 완성).
- **감독 철학** (`types/philosophy.ts`, 오그먼트): 3개 중 1개, 판마다 3회. 예 — 머니볼(1코스트 선구안↑), 스몰볼(번트·도루 자동, 스피드 1단계 무료), 뻥야구(전원 홈런↑ 삼진↑), 4번 몰빵(★★★ 1장 ×2, 나머지 −10%), 오프너(불펜이 선발 가능), ABS 도입(프레이밍 무효), 팜 시스템(★★에 2장), 큰손 구단(이자 상한 7), 육성형(고졸 성장 2배).

## 8. AI 상대와 밸런스 검증

- AI 7팀 원형(`AI_ARCHETYPES`): 뻥야구팀, 스몰볼팀, 용병의존팀, 유망주팀, 수비의팀, 리롤팀, 이자 챙기는 팀. 같은 풀에서 휴리스틱으로 구매·배치·레벨업.
- `pnpm cli bot-arena --games 1000 --seed N` 리포트 지표:

| 지표 | 목표 |
|---|---|
| 판 길이 | 26 ± 4 라운드, 추정 플레이 시간 25분 이내 |
| 강팀 승률 | 보드 종합치 상위 팀이 하위 팀을 이길 확률 65~75% |
| 다양성 | 1등 팀 활성 시너지 조합 상위 5개 점유율 60% 미만, 모든 시너지가 1등 조합에 3% 이상 등장 |
| 철학 편차 | 픽 시 승률 ±8% 이내 |
| 구장 편차 | 승률 ±5% 이내 |
| 기타 | 코스트 5 ★★ 달성률, 평균 팬심 곡선(초반 탈락 과다 여부) |

범위를 벗어나면 원인 파라미터를 리포트에 명시한다.

## 9. 화면 구성 (세로, 한 손)

1. **로비** — 새 게임 / 일일 도전(오늘 시드) / 도감 / 기록 / 설정.
2. **런 화면** — 상단: 스테이지·골드·팬심·상대 7팀 미니 상태. 중앙: 타순 9칸 + 로테이션 3칸(드래그 또는 탭-탭, 시너지 패널 좌측). 하단: 벤치 6칸, 상점 5장, 리롤·XP 버튼(44pt 이상).
3. **경기 화면** — 스코어보드, 텍스트 하이라이트 자동 재생, 결정적 장면 강조, 스킵.
4. **철학 선택 / FA 시장 / 이벤트** — 전체 화면 카드 3장.
5. **결과** — 순위, 최종 보드, MVP, 명장면 3개 스와이프 카드, 공유 이미지(Web Share API).
- 접근성: 최소 폰트 14px, 색 외에 아이콘, 진동 피드백 옵션.

## 12. Phase 1 구현 계획 (승인 요청)

목표: `pnpm cli sim-game --seed X`가 9이닝 박스스코어를 출력하고, 같은 시드는 같은 결과, 1경기 50ms 이내.

1. **`gen/names.ts`, `gen/nicknames.ts`** — 시드 기반 한국식 이름 풀(성 40 × 이름 음절 조합), 외국인 국적별 풀(US/DO/VE/JP/CU/AU). 별명은 Phase 1에서는 규칙 20개 정도의 최소판, Phase 4에서 확장.
2. **`gen/cards.ts`** — 코스트별 템플릿 생성. 코스트가 높을수록 internals 총합↑, 특성 2~3개, 포지션 배분(코스트별 포수·SS·CF·선발·불펜 최소 수 보장). internals → display 유도 함수.
3. **`sim/log5.ts`** — 카테고리 확률(BB/HBP/K/HR/BIP) 산출 + Modifier 적용. 순수 함수, 단위 테스트로 대칭성·리그평균 회귀 검증.
4. **`sim/fielding.ts`, `sim/baserunning.ts`** — 타구 유형·방향 → 수비수 판정 → 안타 종류/아웃/실책/병살/희생플라이. 주자 진루와 도루.
5. **`sim/game.ts`** — 이닝 루프, 타순 순환, DH, AI 감독의 투수 교체(투구수·리드·마무리), `PlayEvent` 로그, 박스스코어, 하이라이트 추출(레버리지 상위 3~5개), MVP.
6. **`sim/resolve.ts`** — `TeamState`/`Board` → `ResolvedTeam`(대체선수 채우기, Modifier 수집 훅. 시너지 계산 자체는 Phase 2지만 인터페이스는 여기서 확정).
7. **CLI `sim-game`** — 랜덤 두 팀 생성 → 경기 → 박스스코어와 하이라이트 텍스트 출력. `--json`으로 `GameResult` 덤프.
8. **검증** — 결정론 테스트(같은 시드 100회 동일), 1000경기 평균 득점 4.5~5.5 / 팀·경기, 삼진·볼넷·홈런율이 기준선 ±15%, 벤치마크 50ms 이내.

Phase 1에서 하지 않는 것: 상점·경제·시너지 계산·AI 구매·UI.
