# Asset licences — 덕아웃 택틱스

All game assets are generated by the project's own source code. Nothing is
downloaded from third parties at build or run time except the three web
fonts below. `sources.json` is the machine-readable manifest;
`pnpm --filter @dugout/assets validate` checks it (also run in CI via tests).

| Asset | How it is made | Source file | Licence |
|---|---|---|---|
| Player figures (3 builds, 6 skin tones, 8 hair styles, 4 beards, caps/helmets/catcher gear, bats, gloves) | Low-poly primitives, instanced | `apps/web/src/scene/figureParts.ts`, `Figures.tsx` | Project (same as repo) |
| Animation clips (28 names from DESIGN §15.4) | Keyframed joint rotations, mirrored for lefties | `apps/web/src/scene/clips.ts` | Project |
| Ballparks (5 variants), crowd, scoreboard, dugouts, cheer stage | Procedural geometry + canvas textures | `apps/web/src/scene/Stadium.tsx`, `park.ts`, `scoreboard.ts` | Project |
| Card portraits | SVG drawn from a deterministic appearance model | `apps/web/src/lib/avatar.tsx`, `appearance.ts` | Project |
| Sound effects (31) and lobby music | Web Audio synthesis (oscillators, seeded noise, envelopes) | `apps/web/src/audio/**` | Project |
| Fonts: Black Han Sans, Bebas Neue, Noto Sans KR | Loaded from Google Fonts | `apps/web/index.html` | SIL Open Font License 1.1 |

Not used, by policy (DESIGN §0, §2): photos or likenesses of real players,
real club names/emblems/uniforms, broadcast audio or cheering songs,
assets of unknown origin. Private real-player packs are built on the
user's device from their own CSV files and are never committed or uploaded.
